# MW P2P QuickShot

Android utility: send latest screenshot to a private Telegram group through a bot. Bot token is entered on the phone and must never be committed to GitHub.

Build: GitHub Actions > Build Android APK. Debug build for personal testing only.

Setup: send `/start@MW_P2P_QuickShot_Bot` in the target Telegram group; enter bot token in the Android app and tap Detect group ID. Grant full image access. Then tap Send latest screenshot.

Security: set this repository to **Private** in Settings. No bot token or personal screenshots are stored here.
